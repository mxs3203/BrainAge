# EEG Brain Score Analysis Pipeline

This project implements an automated pipeline for processing EEG data and computing brain scores using Snakemake. The pipeline is designed to work with data organized by subject in separate folders (e.g., `BA1`, `BA2`, `BA3`, etc.) and performs multiple processing steps—from isolating stimuli to computing both time- and frequency-domain brain scores.

## Overview

The pipeline performs the following steps for each subject/sample:

1. **Stimuli Isolation & Basic Statistics:**  
   - **Script:** `0_isolate_stimuli.py`  
   - **Output:**  
     - `0_total_data.csv`: Consolidated data for all stimuli.  
     - `0_mean_sd.csv`: Mean and standard deviation of EEG channels.
   
2. **Quality Filtering:**  
   - **Script:** `1_inspect_quality.py`  
   - **Output:** `1_quality_filter.csv` – A report based on quality thresholds.

3. **Normalization:**  
   - **Script:** `2_normalize_stimuli.py`  
   - **Output:** `2_normalized_data.csv` – EEG data normalized across stimuli.

4. **Frequency-Domain Analysis (FFT):**  
   - **Script:** `3_perform_fft.py`  
   - **Output:** `3_fft_data.pck` – FFT data saved as a pickle file.

5. **Brain Score Computation (Time Domain):**  
   - **Script:** `4_compute_brain_score.py`  
   - **Output:** `4_brain_score.csv` – Brain score computed from the normalized EEG data.

6. **Brain Score Computation (Frequency Domain):**  
   - **Script:** `5_compute_brain_score_fft.py`  
   - **Output:** `5_brain_score_fft.csv` – Brain score computed from FFT data.

Final results for each sample are stored in `results/{sample}/` and log files are maintained in `logs/`.


Each subject folder in the `results/` directory contains output files generated by each Snakemake rule.
